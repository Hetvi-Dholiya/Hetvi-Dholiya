## About Me

I'm **Hetvi Dholiya**, a Computer Science undergraduate interested in building reliable software and understanding the systems behind it.

My primary focus is **full-stack development**, with experience building web applications from the interface all the way to APIs, databases, authentication, and deployment.

I'm also strengthening my foundations in **Data Structures & Algorithms, problem solving, and computer science fundamentals**.

I enjoy working on projects where I can go beyond simply making something work, understanding *why* it works, how it scales, and how it can be made simpler.

- Building full-stack applications and experimenting with new ideas
- Practicing Data Structures & Algorithms
- Working with modern web technologies and backend systems
- Exploring cross-platform application development
- Participating in hackathons and building under real constraints
- Writing about things I learn and problems I encounter
- Linux enthusiast and CLI-first developer
